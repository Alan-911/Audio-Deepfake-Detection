# Contributing

This repository is maintained as a portfolio engineering project.

1. Open an issue explaining the intended correction or improvement, without posting sensitive information.
2. Work on a branch; submit a pull request instead of committing directly to protected branches.
3. Explain **what changed, why, how it was verified**, and any deployment implications.
4. Do not add credentials, customer/patient data, unauthorized third-party material, or unsupported claims.
5. Update the README and relevant documentation when behavior or evidence changes.

Research changes should record dataset provenance, split definitions, seeds, hyperparameters and evaluation methodology.

A green CI badge only confirms that its specified checks ran successfully.
